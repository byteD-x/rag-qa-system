# 工作区页签与大盘优化

## 变更

- `MainLayout` 增加右侧工作区页签：路由进入即打开、最多保留 8 个、业务总览固定、其他页签可关闭；使用 `KeepAlive` 保留页面状态。
- `EntryView` 增加总览、知识库健康、问答质量、使用反馈四个视角。
- 总览先展示范围、统计窗口、核心指标和待处理事项；个人视图偏向日常行动，全局视图偏向运营治理。

## 验证

- `cd apps/web && npm run test:unit`：26 个测试文件、59 个用例通过。
- `cd apps/web && npm run build`：1682 个模块构建通过。
- 本地 Vite 预览验证了业务总览与统一问答之间的工作区页签切换。
